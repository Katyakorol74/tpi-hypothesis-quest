# TPI Hypothesis Quest — стартовая версия

Это первый технический прототип приложения Академии ТПИ.

## Что уже реализовано

- вход без формы регистрации: анонимная Supabase-сессия и выбор команды;
- переключение между командами;
- общая рабочая комната;
- два документа: диагностическое заключение и паспорт эксперимента;
- автоматическое сохранение командных ответов в Supabase;
- синхронизация изменений через Supabase Realtime;
- режим просмотра, если занятие уже имеет статус `locked`.

## Что ещё не входит в эту версию

- кабинет тренера;
- создание занятий из интерфейса;
- кнопка финальной фиксации и безопасная блокировка записи на уровне базы;
- Google Sheets / Excel-выгрузка;
- отдельный экран повторной встречи через месяц.

Эти функции будут добавлены следующими итерациями.

## 1. Настройка Supabase

В файле `config.js` укажите:

- `SUPABASE_URL` — Project URL;
- `SUPABASE_PUBLISHABLE_KEY` — Publishable key (`sb_publishable_...`);
- `WORKSHOP_CODE` — код занятия, по умолчанию `TPI-TEST-01`.

Не используйте Secret key или `service_role` key в браузере.

## 2. Загрузка в GitHub

1. Откройте репозиторий `tpi-hypothesis-quest`.
2. Нажмите **Add file → Upload files**.
3. Загрузите `index.html`, `styles.css`, `config.js`, `app.js` и `README.md` в корень репозитория.
4. Нажмите **Commit changes**.

## 3. Публикация на Cloudflare Pages

1. Откройте Cloudflare Dashboard → Workers & Pages.
2. Создайте Pages application и выберите подключение к Git.
3. Выберите репозиторий `tpi-hypothesis-quest`.
4. Для чистого статического сайта без сборщика:
   - Build command: `exit 0` (или пусто, если интерфейс допускает);
   - Build output directory: `/` либо `.` — выберите значение, которое принимает форма; корень репозитория должен содержать `index.html`.
5. Запустите deployment.

## 4. Проверка

1. Откройте выданный адрес `*.pages.dev`.
2. Выберите Команду 1.
3. Введите тестовый текст в поле «Как мы формулируем проблему?».
4. Откройте этот же адрес в другом браузере или на другом устройстве.
5. Выберите Команду 1 и проверьте, что текст появился.
6. Измените текст во втором окне и убедитесь, что первое окно получает обновление.
7. Перезагрузите страницу и проверьте сохранение.

## Важно о сохранении

Ответы хранятся в Supabase, а не в локальном хранилище браузера. Supabase JS сохраняет техническую анонимную сессию в браузере, чтобы участник не создавал новую идентичность при каждом обновлении страницы. Это не является местом хранения ответов.

На текущем этапе не используйте приложение для конфиденциальных производственных данных: вход участника основан на выборе команды, без индивидуального пароля.
